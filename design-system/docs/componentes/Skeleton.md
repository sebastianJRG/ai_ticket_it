# Skeleton

Placeholders de carga con pulso suave, con la misma forma que el contenido final.

- Usar en listas y cards mientras cargan (nunca un spinner a pantalla completa).
- Base `surface-raised`, brillo `skeleton-highlight`, ciclo `duration-skeleton`. Con "reducir movimiento" activo, sin animación.
- `EventCardSkeleton` en variantes feature y compact; mostrar 2–3 seguidos.
