# ReviewCard

Card de reseña: usuario, puntaje en estrellas, comentario, fecha y tipo de entrada con el que asistió.

- Las reseñas solo existen para compras UTILIZADAS, por eso se muestra "Asistió con Platea preferencial" como prueba de origen.
- Comentario completo hasta 6 líneas; más, con "Leer más".
- En el detalle del evento se muestran las 2 más recientes del organizador + "Ver las 1.284 reseñas".
