# Tabs

Pestañas para alternar vistas del mismo contenido, con contador opcional.

- `underline` para filtrar listas (Activas / Pasadas / Canceladas; Todas / Pendientes / Confirmadas…). Indicador de 3px en `primary`, contadores en pill.
- `segmented` para 2–3 vistas de una misma entidad (Detalle / Chat en la compra).
- Máximo 4 pestañas visibles; más, con scroll horizontal.
- `accessibilityRole="tab"` y `accessibilityState={{ selected }}`.
