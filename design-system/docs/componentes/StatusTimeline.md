# StatusTimeline

Línea de tiempo vertical con el historial de estados de una compra (CambioEstadoCompra).

- Un nodo por cambio, con el ícono y colores del estado; el último está marcado como actual (anillo).
- Cada ítem: estado, fecha y hora, quién lo cambió si no fue el sistema ("Vos", el organizador) y nota opcional (medio de pago, monto reembolsado).
- Orden cronológico de arriba hacia abajo. Va en la pestaña *Detalle* de la compra.
