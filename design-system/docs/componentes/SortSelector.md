# SortSelector

Disparador compacto "Ordenar: Precio ↑" y lista de opciones de orden en radio.

- Opciones del dominio: Fecha más próxima (por defecto), Precio menor a mayor, Precio mayor a menor, Mejor puntaje del organizador.
- `SortSelector` va a la derecha del contador de resultados; al tocar abre un `BottomSheet` con `SortOptions`.
- El cambio se aplica al tocar (no requiere "Aplicar") y cierra el sheet.
