# BottomSheet

Panel que sube desde abajo para opciones, filtros y orden.

- Esquinas superiores `radius-xl`, grabber, título + botón cerrar, padding `space-5` y safe area inferior.
- Footer con acciones a lo ancho: secundaria (Limpiar) + primaria con resultado ("Ver 24 eventos").
- En RN usar `@gorhom/bottom-sheet` con snap points al contenido; fondo `scrim-modal`.
- Preferirlo a un Modal para cualquier elección (orden, filtros, Select).
