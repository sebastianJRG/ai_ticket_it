# Icon

Set de íconos de trazo (24 × 24, trazo 2, extremos redondeados) usado en toda la app.

- En React Native usar **lucide-react-native** con `strokeWidth={2}`; los nombres de este set mapean a Lucide (search → Search, mapPin → MapPin, hourglass → Hourglass, checkCircle → CircleCheck, xCircle → CircleX, ticketCheck → TicketCheck, undo → Undo2, sliders → SlidersHorizontal, sort → ArrowUpDown, theater → Drama, festival → Tent, mic → Mic, trophy → Trophy).
- Tamaños: 16 en badges y metadatos, 20 en botones e inputs, 24 en navegación y header.
- Heredan el color del texto que acompañan. Íconos con significado propio (estado) necesitan ≥3:1 con el fondo.
- No usar emojis como íconos.
