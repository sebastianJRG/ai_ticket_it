# Avatar

Avatar circular con iniciales y color determinístico a partir del nombre.

- Tamaños: 32 (reseñas, chat), 40 (filas del organizador), 64 (perfil).
- Si hay foto de perfil, mostrarla recortada en círculo; las iniciales son el fallback.
- Decorativo (`accessible={false}`): el nombre siempre está escrito al lado.
